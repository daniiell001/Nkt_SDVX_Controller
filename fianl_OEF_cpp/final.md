  ---
  技术栈

  编译环境：Arduino-Pico（rp2040:rp2040:rpipico）

  核心组件

  1. DMA 驱动的 I2C 连续读取

  RP2040 的两个硬件 I2C 外设（I2C0、I2C1）各有独立的 DMA 触发线。做法：

  DMA control block chain:
    [写寄存器地址 0x0C] → [RESTART + 读 2 字节] → [写结果到 buffer] → [loop]

  每次 I2C 事务自动完成，结果写入环形缓冲区。两个 DMA 通道完全并行运行。CPU 随时读 ring_buf[latest] 拿最新的角度值。

  2. USB HID @ 1kHz

  TinyUSB 的鼠标报告描述符（绝对坐标或相对位移）。关键：用 USB SOF（Start of Frame）中断触发主循环，每 1ms 一次，与主机
  USB 轮询精确同步。这是罗技/雷蛇等游戏鼠标的做法。

  3. 信号处理管线

  直接把 code_advanced 的 Python 管线翻译成 C：
  - 软死区 → if (abs(d) < DEAD_ZONE) ...
  - 1€ 滤波器 → 浮点运算，RP2040 M0+ 算得动（1ms 内绰绰有余）
  - Power curve → powf()
