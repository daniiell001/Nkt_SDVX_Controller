# SDVX 手台控制器 — RP2040-Tiny + AS5600
基于 WaveShare RP2040-Tiny 的 SDVX手台控制器: 两个 AS5600 磁编码器控制 X/Y 轴，七个键盘轴作为输入按键，通过 USB HID 输出鼠标移动和键盘按键。

鼠标输出加了死区消抖 + 子像素累加器，让移动消除抖动且丝滑连贯。

本手台为轻薄便携台，长宽&厚度相比其他手台小很多，重量在600g左右，但按键间距和布局1:1还原官台。

其中pcb分为四部分，每一块pcb尺寸都小于10cm*10cm,可使用嘉立创白嫖零成本搞定。为了方便焊接，本手台直接采用RP2040-Tiny直焊在pcb上,通过fpc线连接type-c接口模块。
（现已增加整合版pcb，方便焊接）

手台外壳、键帽和旋钮（除黄铜旋钮帽）均采用3D打印，其中外壳面板和底座分为左右两部分，尺寸不超过18cm*18cm（因为本人打印机是拓竹A1mini打不了更大的），利用固定件和pcb来连接左右两边底座与面板打印件。

## 旋钮工作原理

旋钮组成：旋钮帽，旋钮轴，径向磁铁，AS5600 磁编码器芯片

- 12 位磁旋转编码器芯片，能感应磁铁旋转角度
- RP2040 读取两次角度值的差值 (delta)，换算为鼠标移动量
- 4096 counts = 一圈 (360°)，delta 取半圈判定法处理 0° 环绕

### 信号处理管线

完整管线流程：**死区 → 1€ 滤波器 → Power Curve → 方向消抖**

#### 1. 死区

过滤编码器微小抖动，支持**软死区**（代码中未启用）：
- 绝对值 < `DEAD_ZONE`：输出 0
- 在 `DEAD_ZONE` ~ `SOFT_END` 之间：线性渐变过渡
- 大于 `SOFT_END`：原样通过

#### 2. 1€ 滤波器
自适应低通滤波器
- **低速时**：低截止频率 → 强平滑 → 消除手抖
- **高速时**：高截止频率 → 低延迟 → 快速响应

参数：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| `FC_MIN` | 最小截止频率 | 2.5 Hz |
| `BETA` | 速度系数 | 0.025 |
| `FC_D` | 速度平滑截止频率 | 1.0 Hz |

#### 3. Power Curve（响应曲线）

对手感曲线塑形：`output = sign(input) × |input|^POWER`
- `POWER > 1.0`：低速区更精细，高速区加速更快
- `POWER = 1.0`：线性响应
- `POWER < 1.0`：低速区灵敏，高速区压限

#### 4. 方向消抖

旋钮快速来回切换方向时，锁死输出若干毫秒，避免方向闪烁导致的来回抖动。
默认消抖时间：3ms。

#### 5. 子像素累加

经管线处理后的浮点位移量，累积到超过 ±1 像素后才发送 Mouse 报告。保证低速微动也能产生平滑的整数位移，而非直接截断丢失精度。

## 引脚定义

| 引脚 | 功能 | 说明 |
|------|------|------|
| GP4 | SDA0 (I2C0) | 编码器 X — AS5600 数据线 |
| GP5 | SCL0 (I2C0) | 编码器 X — AS5600 时钟线 |
| GP6 | SDA1 (I2C1) | 编码器 Y — AS5600 数据线 |
| GP7 | SCL1 (I2C1) | 编码器 Y — AS5600 时钟线 |
| GP0 | BT-A | 按钮 → 键盘 `D` |
| GP1 | BT-B | 按钮 → 键盘 `F` |
| GP2 | BT-C | 按钮 → 键盘 `J` |
| GP3 | BT-D | 按钮 → 键盘 `K` |
| GP8 | FX-L | 按钮 → 键盘 `C` |
| GP9 | FX-R | 按钮 → 键盘 `M` |
| GP10 | START | 按钮 → 键盘 `Y` |
| GP16 | NeoPixel | WS2812 RGB LED |

## LED 状态说明

| 颜色 | 含义 |
|------|------|
| 蓝色 (0x0000FF) | 初始化中 |
| 紫色 (0xFF00FF) | 按钮按下（亮 100ms 后熄灭） |
| 红色 (0xFF0000) | 停止/错误 |
| 熄灭 | 空闲运行中 |
